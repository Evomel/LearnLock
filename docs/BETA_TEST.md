# LearnLock — закрытый семейный бета-тест

## Цель

Проверить core loop на 5–10 семьях: задача после сна → ответ → сессия → повтор; понять фрустрацию ребёнка и надёжность на разных прошивках.

## Профиль участников

- Возраст ребёнка 6–12
- Один Android-телефон ребёнка (Android 10+)
- Родитель готов выдать Accessibility / overlay / батарею

## Чеклист установки (день 0)

- [ ] Установлен debug/APK
- [ ] Создан PIN родителя
- [ ] Включены overlay + Accessibility + игнор батареи
- [ ] На прошивке Xiaomi/Huawei/Samsung включён автозапуск (если есть)
- [ ] Возраст и микс задач выставлены
- [ ] Сессия 15 минут на старте
- [ ] «Показать экран задачи» работает

## Сценарии (дни 1–7)

1. **После сна** — погасить экран на 30 с, разблокировать системным PIN/свайпом: появляется задача LearnLock.
2. **Верный ответ** — доступ есть ~15 мин, повторной задачи нет.
3. **Истечение сессии** — после таймера или «Завершить сессию» снова задача.
4. **Ошибки** — 3 неверных ответа подряд → задача упрощается, есть короткая пауза.
5. **Подсказка** — одна на экран lock (если включено).
6. **PIN родителя** — снимает блокировку; в статистике виден `PARENT`.
7. **Окно активности** — вне окна режим «Без задач» не показывает lock.
8. **Перезагрузка** — после reboot мониторинг поднимается, lock снова работает.

## Вопросы родителю

- Сколько раз за день использовали родительский PIN?
- Были ли моменты, когда задача не появилась после сна?
- Ребёнок злится / бросает / воспринимает как игру?
- Какие категории слишком лёгкие/сложные?

## Антифрустрация (уже в MVP)

- Пауза 2 с после ошибки
- `forceEasier` после N ошибок подряд
- Крупный шрифт, один вопрос на экран
- Подсказка (опционально)

## Критерии успеха беты

- ≥70% разблокировок через задачу, не через PIN
- На ≥2 брендах телефонов сценарий «после сна» стабилен
- Нет жалоб на краши / невозможность выйти родителю
