# Обходы и честные ограничения (для родителя)

LearnLock MVP **не является** корпоративным kiosk. Цель — учебная привычка и трение, а не непреодолимый замок.

## Известные обходы

| Обход | Комментарий |
|-------|-------------|
| Safe Mode | Сторонние сервисы могут не стартовать |
| Второй пользователь / гость | Отдельный профиль без LearnLock |
| Force-stop / отключение Accessibility | Ребёнок со знаниями может ослабить защиту |
| ADB / recovery | Технический обход |
| Удаление приложения | Ослаблен Device Admin (опционально, не обязателен в MVP) |

## Что усиливает защиту в MVP

- Foreground service после включения блокировки
- Реакция на `USER_PRESENT` / `SCREEN_ON`
- Accessibility возвращает экран задачи, если ушли в другое приложение при истёкшей сессии
- Родительский PIN (хеш PBKDF2) для emergency unlock

## Рекомендации родителю

1. Не сообщать ребёнку PIN.
2. На Xiaomi/Huawei закрепить автозапуск и снять ограничения батареи.
3. Для максимальной жёсткости (школа / киоск) — отдельный режим Device Owner (post-MVP).
4. Если ребёнок часто «ломает» защиту — снизить фрустрацию (сессия длиннее, сложность −1), а не только ужесточать.

## Play Store

Формулировать продукт как educational parental tool. Accessibility — только для возврата к задаче, без чтения содержимого чужих окон (`canRetrieveWindowContent=false`).
